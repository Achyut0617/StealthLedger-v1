# StealthLedger Finance UI

A responsive React dashboard starter with Overview, Transactions, Budgets, and Privacy Settings screens.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Stack

- React + Vite
- Recharts for the cash-flow visualization
- Lucide React icons
- Plain CSS (no Tailwind or component library)

## Notes

This is a frontend demonstration. Data is currently held in `src/data.js` and React state; it is not connected to a backend, authentication, persistent storage, or the previous Python steganography/blockchain implementation. Replace demo values and connect API calls before production use.
